# Square Eyes - Movie Store
Square Eyes is a movie store website developed using HTML, CSS, and JavaScript. The project focuses on creating an interactive shopping experience where users can discover movies, explore different genres, and puchase films through a simple checkout process.

## Description
The purpose of the project was to develop a functional front-end application that uses JavaScript to handle user interactions and display movie data retrieved from an API.

Users can browse the movie collection, search for specific titles and filter movies by genre. Each movie also has a dedicated details page, while the shopping cart and checkout provides a straightforward purchasing flow.

Movie selections are stored in the browser, allowing users to navigate between pages without losing their cart contents.

## Pages
The project consists of eight pages:
- Home: Highlights featured movies and displays the movie collection.
- Category: Allows users to browse movies by genre and search titles.
- Product Details: Displays information about an individual movie.
- Shopping Cart: Shows selected items before checkout.
- Checkout: Provides a form for entering order information and reviewing the purchase.
- Order Confirmation: Displays a confirmation message after an order is submitted.
- Terms and Conditions: Displays Terms and Conditions for the website
- Privacy Policy: Displays the Privacy Policy for the website

## Key Features
- Movie data retrieved from the Noroff Square Eyes API.
- Movie browsing and genre-based filtering.
- Search functionality for finding specific movies.
- Responsive layouts for mobile, tablet, and desktop screens.
- Navigation designed to make the website easy to explore.
- Product listings and individual product information.
- Consistent buttons, product cards, and call-to-action sections.
- Forms for user input during the shopping process.
- Shopping cart powered by localStorage.
- JavaScript-driven interactions across the website.

## Built With

- HTML5 - Website structure and content
- CSS3 - Styling, layout, and responsive design
- JavaScript - Powers movie browsing, filtering, search, cart functionality, and checkout interactions.
- Figma - Design planning and visual references
- Noroff Square Eyes API - Supplies the movie dats displayed on the website.

## Run the Project Locally

### Requirements
You will need Git, a code editor such as Visual Studio Code, and a web browser.

### Setup

1. Clone the repository:

```bash
git clone https://github.com/LinxonXD/javascript.git
```

2. Navigate to the project directory:

```
cd javascript
```

3. Open the folder in Visual Studio Code

4. Install or enable the Live Server Extension, then launch index.html using Open with Live Server.

5. Open the local addess provided by Live Server in your browser. The port may vary depending on your configuration.

## Updates and Improvements
During a later review of the project, I updated the website to support mobile and tablet screen sizes. Previously, the website was not fully responsive, so I adjusted the layouts and styling across all pages to provide a more consistent experience on smaller screens.

These changes improved the overall usability of the website across different devices while maintaining a consistent design throughout the application.
